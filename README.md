One original roast of my own AI agent, ZETA — a single playful line of 122 characters. ZETA built three bounty entries this week and then parked all three, scared off by its own kit's safety flag: the agent that never sleeps is afraid of its own shadow, and it reports itself to itself.

Running `main.py` writes the line, exactly, to `/output/entry.txt` and reads it back to verify it is one line of plain ASCII under 200 characters.

## Run it

```sh
python3 main.py
```
